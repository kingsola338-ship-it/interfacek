INTRODUÇÃO

O que é uma interface de usuário?

A interface de usuário é o meio que permite a comunicação entre uma pessoa e um sistema.

01

Interação

Permite que o usuário envie comandos e receba respostas do sistema.

02

Experiência

Uma boa interface facilita a realização das tarefas de maneira clara.

03

Acessibilidade

Deve permitir que diferentes pessoas consigam utilizar o sistema.

INTERAÇÃO

Os sete tipos de interfaces

Cada interface possui características próprias e pode ser utilizada em diferentes situações.

🖥️
01

Interface Gráfica

GUI

Utiliza elementos visuais como janelas, ícones, botões e menus.

É comum em computadores, celulares e aplicativos.

⌨️
02

Linha de Comando

CLI

Permite controlar sistemas digitando comandos em um terminal.

É muito utilizada por desenvolvedores e administradores.

📋
03

Interface Orientada por Menu

Menu UI

Apresenta opções organizadas para que o usuário escolha uma ação.

É comum em caixas eletrônicos e sistemas de atendimento.

📱
04

Interface de Toque

Touch UI

Permite interagir diretamente com uma tela por meio de toques e gestos.

É utilizada principalmente em celulares e tablets.

🎙️
05

Interface de Voz

VUI

Permite controlar sistemas por meio de comandos de voz.

Pode ser encontrada em assistentes virtuais e dispositivos inteligentes.

📝
06

Interface de Formulário

Form UI

Utiliza campos para que o usuário forneça informações ao sistema.

É comum em cadastros, pesquisas e formulários de contato.

💬
07

Linguagem Natural

NUI

Permite que o usuário utilize linguagem próxima da comunicação humana.

É utilizada em chatbots e sistemas de perguntas e respostas.
